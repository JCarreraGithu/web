#Sistema de Gestión de Personal y Tiendas (Symfony)

Aplicación web desarrollada en **Symfony** para la administración centralizada de empleados, asignación 
de puestos de trabajo, control de sucursales/tiendas y seguimiento del desempeño laboral mediante un módulo de logros.

---

#Funcionalidades Identificadas

* **Gestión de Empleados:** Mantenimiento de la información del personal de la empresa (`Empleados`).
* **Estructura Organizacional:** Control de los diferentes cargos y roles dentro de la organización (`Puestos`).
* **Red de Sucursales:** Registro y administración de las ubicaciones físicas o puntos de venta (`Tiendas`).
* **Evaluación y Logros:** Registro de metas alcanzadas, incentivos o hitos del personal (`Logros`).

---

#Tecnologías Utilizadas

* **Framework:** Symfony (PHP 8.x)
* **ORM:** Doctrine ORM (para el mapeo de entidades y persistencia de datos)
* **Plantillas:** Twig (Motor de plantillas HTML/CSS)
* **Frontend Assets:** JavaScript (27.4%), CSS (0.3%), Importmaps / AssetMapper
* **Contenedores:** Docker (Soporte mediante `compose.yaml` y `compose.override.yaml`)
* **Pruebas:** PHPUnit
